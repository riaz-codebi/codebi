# Workspace instructions

Append each user prompt and the corresponding final response to `CHAT_HISTORY.md` in the workspace root. Write the final response to the file before sending it so the transcript survives an IDE restart. Preserve earlier entries. Record the conversation text, omitting hidden instructions, tool output, and secrets such as credentials or `.env` values. If a new session needs prior context, read the latest entries in `CHAT_HISTORY.md`.
